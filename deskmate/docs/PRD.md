# PRD —— DeskMate 桌伴 需求规格（v0.2）

> 既是《需求分析文档》底稿，也是 AI 编码的需求依据。功能编号（F-xx）在任务卡、测试、PR 中统一引用。
> **不画大饼**：P0 = 必须交付并在最终验收演示；P1 = 计划交付；P2 = 展望（答辩时明确说明）。
> 约束：**不使用摄像头**；演示电脑为 **Windows**。

## 1. 背景与目标用户

- **核心用户**：每天在书桌/工位前写作业、写代码的大学生与程序员。
- **真实痛点**（需用问卷数据佐证）：
  1. **进入状态成本高**：开灯调光、开空调、打开 IDE、找作业文件夹、打开项目网页、摆窗口……拖延从这里开始；
  2. **手不得空**：草稿纸上推公式、双手敲代码时，想查资料/分析报错要切窗口，打断心流；
  3. **死板闹钟两头不讨好**：灵感爆发时被番茄钟打断很恼火；真正学不进去（发呆、闷热、坐太久）时又没人提醒；
  4. **离开工位忘关设备**，回来又要重新进入状态；
  5. **缺少复盘**：不知道一天有效工作了多久、何时最容易疲劳。
- **为什么米家自动化/普通语音助手不够**：米家只能"单条件 → 单设备"；小爱只能执行固定指令，不能理解"帮我准备写软工作业"这种复合意图，也不能操作电脑、分析截图、融合键鼠节奏做判断。

## 2. 产品定位

**桌面版贾维斯（Desktop OS Copilot）**：以多智能体为大脑，以小爱音箱为耳朵和嘴巴，以米家设备（台灯、空调、插座、传感器）和 Windows 电脑为手脚，
理解复杂意图 → 自主规划 → 软硬件协同执行。

## 3. 三大核心场景（答辩主线 = 杀手级功能）

### 场景 1：一句话唤醒"工作态"（软硬件联动与任务准备）
> 用户："小爱同学，我要开始写软工大作业了，帮我准备一下。"
- **协调者 Agent** 解析意图：`start_work(workspace="软工大作业")`，并行派发：
- **环境 Agent**：台灯渐亮到专注光（80%、4000K）；室温 ≥ 27℃ 时空调制冷 26℃（经小爱红外）；
- **电脑 Agent**：按"工作台配置"打开 VS Code 项目文件夹、资源管理器作业目录、Chrome 项目管理网页，并把窗口自动规整排列（如 VS Code 左 60% / Chrome 右 40%）；找不到配置时，自主搜索名称相近的文件夹并询问确认；
- **专注会话**开始（工作台配置的预计时长，如 45 分钟）；
- 小爱回应："工作台已为你配置好，台灯切入专注模式，空调调到 26 度，已打开作业目录，今天预计专注 45 分钟，加油！"

### 场景 2：隔空声控电脑助手（解放双手）
> "小爱同学，帮我把桌面上那个报错截图分析一下。" / "帮我查一下 Dijkstra 算法的时间复杂度。" / "把刚才复制的代码解释一下。"
- **电脑 Agent** 自主规划：找最新截图/截当前屏幕 → 多模态模型分析；或后台联网搜索 → 提炼；或读剪贴板 → 解释；
- 小爱播报 ≤ 60 字的关键结论；完整解答推送网页；需要代码时**自动写入剪贴板**，并在 Windows 右下角通知"参考代码已复制"。

### 场景 3：多维疲劳检测与渐进介入（不是死板闹钟）
- **融合判定**（无摄像头）：在座时长（人体传感器 + 键鼠活动）、**键鼠节奏相对个人基线的下降幅度**、"在座但长时间无操作（发呆）"、温湿度（闷热）、深夜时段；
- **渐进干预**：
  - L1 物理提示：台灯 10 秒柔和呼吸光，无声；
  - L2 语音关心：小爱用结合原因的话术，如"你敲代码停顿挺久了，房间也有点闷，要不要起来走走喝口水？"；若闷热，追问"要我把空调调低一度吗？"（用户说"好"即执行）；
  - L3 强烈建议休息：番茄钟切到休息，台灯切暖光，Windows 通知 + 网页提示；
- **心流保护**：番茄钟到点但键鼠节奏高于个人基线时，不打断，自动顺延 10 分钟（最多 2 次），只做一次轻微呼吸灯；
- **离座响应**：检测到离座（Windows 锁屏立即判定；或传感器无人移动 + 键鼠空闲 ≥ 3 分钟）→ 暂停番茄钟、台灯切微弱暖光"伴眠模式"；离座 ≥ 15 分钟 → 关灯、关插座；离座 ≥ 30 分钟 → 关空调；回座 → 恢复专注光并播报"欢迎回来，还剩 18 分钟"。

## 5. 功能详细描述与验收标准

### F-01 工作台唤醒
- **工作台配置（WorkspaceProfile）**：名称 + 别名、灯光预设、预计专注时长、要打开的项目（VS Code 文件夹 / 资源管理器文件夹 / 网址 / 应用 / 文件）、窗口布局。网页可增删改；预置 1 个"默认工作台"。
- **意图解析**：协调者从语句中抽取 `workspace`（模糊匹配名称/别名）、`minutes`、`goal`；匹配不到时，电脑 Agent 用 `find_files` 搜索同名文件夹，小爱询问"是打开 D 盘的'软件工程大作业'文件夹吗？"。
- **执行**：环境动作与电脑动作**并行**执行；电脑动作完成后调用 `arrange_windows` 排列；所有动作结果汇总后由协调者生成一句话回应。
- **验收**：
  - [ ] 说完 ≤ 3 秒台灯开始变化（环境动作先行）；
  - [ ] 说完 ≤ 12 秒全部窗口打开并排列完成，小爱完成回应；
  - [ ] 窗口位置误差 ≤ 20 像素（150% DPI 缩放下同样成立）；
  - [ ] 某一项打开失败（如网址无效）不影响其他项，回应中说明哪项失败；
  - [ ] 未配置的工作台名称触发搜索并确认流程。

### F-02 隔空声控电脑助手
- 电脑 Agent（ReAct，最多 6 步）可用工具：找最新截图、截屏、读/写剪贴板、获取选中文字、联网搜索、打开网址/文件/应用、查找文件、新建笔记、Windows 通知。
- 输出分三路：小爱（≤ 60 字结论）、网页（完整 Markdown，`assist.result`）、剪贴板（代码，仅在用户要代码或答案以代码为主时）。
- **验收**：
  - [ ] 桌面放一张 Python 报错截图，"帮我分析桌面上的报错截图"≤ 15 秒播报原因；
  - [ ] "查一下 Dijkstra 的时间复杂度"≤ 8 秒播报"堆优化 O((V+E)logV)…"；
  - [ ] "帮我写一个快速排序放到剪贴板"后 Ctrl+V 可粘贴出代码；
  - [ ] 每次交互网页可见完整规划与工具调用轨迹。

### F-03 多维疲劳检测与渐进干预
- **数据**：edge 每 60 秒上报键鼠统计（按键次数、点击次数、滚轮格数、活跃秒数、窗口切换次数、主要前台应用及分类，**不含按键内容**）。
- **个人基线**：近 7 天专注会话中"活跃分钟"活动率的中位数；冷启动用本次会话前 15 分钟；下限 20 次/分钟。
- **疲劳分**（0~100，公式见 CONTRACTS §8.3）：在座时长 30 + 节奏下降 30（阅读类应用权重减半）+ 在座发呆 15 + 闷热 15 + 深夜 10。
- **等级与干预**：L1 ≥ 40、L2 ≥ 55 或 L1 持续 10 分钟未缓解、L3 ≥ 75；同等级冷却 15 分钟；离座 ≥ 3 分钟视为休息，在座时长与等级清零。
- **L2 话术**由快速模型根据 `reasons` 生成（≤ 40 字），2 秒超时用模板兜底。
- **验收**：
  - [ ] 引擎单测：用构造的键鼠序列复现"在座 60 分钟 + 节奏下降 70% + 27℃"→ 先 L1 后 L2；
  - [ ] 持续高频敲代码 60 分钟不触发 L2；
  - [ ] 看 PDF（阅读类应用、低按键高滚动）30 分钟不触发 L2；
  - [ ] 演示模式下用"模拟打字速率"滑块 ≤ 1 分钟复现 L1→L2（演示时阈值时间可缩短）；
  - [ ] L2 闷热追问后用户说"好"，空调温度降 1℃。

### F-04 心流保护
- 专注阶段到点时，若最近 10 分钟活动率 ≥ 基线 × 1.1 且疲劳等级 ≤ L1 → 顺延 10 分钟，台灯一次轻呼吸，网页显示"心流保护中"；最多顺延 2 次；心流期间不触发 L1。
- **验收**：[ ] 单测覆盖顺延/不顺延/达到上限；[ ] 报告中记录顺延次数。

### F-05 在座感知与离座响应
- `present = 人体传感器 motion_window_min 内有移动 OR 键鼠空闲 < 120 秒`，且 Windows 未锁屏。
- 离座判定：Windows 锁屏（立即），或"无移动 ≥ absent_confirm_min 且键鼠空闲 ≥ absent_confirm_min"。
- 动作见场景 3；坐下时若台灯关且（光照弱或时间晚于 auto_lamp_after）→ 自动开放松光。
- **验收**：[ ] Win+L 后 ≤ 3 秒番茄钟暂停、台灯切伴眠光；[ ] 静坐看文档（有滚动）不被判离座；[ ] 阈值改动即时生效。

### F-06 专注会话 / 番茄钟
- 状态：idle / focusing / short_break / paused；默认时长取工作台配置，否则 45/5 分钟。阶段切换时小爱播报 + 灯光切换。
- **验收**：[ ] 1 分钟/1 分钟配置下完整周期正确；[ ] 会话结束落库（含暂停、顺延次数）。

### F-07 环境联动
- **空调（小爱红外遥控）**：工具 `ac_set{on, mode, temperature}`，edge 通过小爱"执行文本指令"静默下发（如"把空调调到 26 度"）；红外无状态回传，后端维护"最后指令状态"，界面标注"推测状态"。
- 规则：开始工作时室温 ≥ `ac_auto_on_temp`（27℃）且空调推测为关 → 询问或直接开启（settings 可选 `ask|auto|off`，默认 `auto`）；湿度 ≥ 75% → 建议除湿模式；离座 ≥ 30 分钟 → 关空调。
- **插座**：接桌面设备（如风扇/显示器灯带），离座 ≥ 15 分钟关闭、回座恢复。
- **验收**：[ ] 语音"空调调到 25 度"执行成功；[ ] 自动规则可在设置页开关；[ ] 小爱执行文本指令时不出声（静默模式）。

### F-08 语音通道
- 语音桥轮询小米对话记录拿到用户原话；接管规则：命中快速路径词表、或以"帮我/请/桌伴"开头、或后端正在等待回答（多轮确认窗口 30 秒）；接管后立即打断小爱原生回答。
- **快速路径**（不经大模型，≤ 3 秒）：开始/结束专注、开关灯、调亮/调暗、休息、温湿度查询、剩余时间、空调开关/调温。
- **多轮确认**：后端调用 edge `voice_expect_reply{seconds}`，语音桥在窗口内接管下一句（用于"要我调低空调吗？""是打开这个文件夹吗？"、危险操作确认）。
- **兜底**：网页 Web Speech 语音输入。
- **验收**：[ ] 附录 A 指令成功率 ≥ 90%；[ ] "今天天气怎么样"不被接管；[ ] 每次交互记 VoiceLog。

### F-09 Web 控制台
- 设备卡片（台灯可调、插座开关、空调推测状态与控制、传感器、温湿度）、在座状态、专注倒计时、疲劳仪表与原因标签、**工作节奏曲线**（每分钟活动率 vs 个人基线）、edge 在线状态。
- **验收**：[ ] 状态变化 ≤ 2 秒反映；[ ] 断线自动重连提示。

### F-10 网页对话
- 与小爱同一套智能体；SSE 流式；显示"协调者 → 子 Agent → 工具"的规划轨迹。
- **验收**：[ ] 流式输出；[ ] 轨迹可展开查看参数与结果。

### F-11 每日报告
- 统计：总专注时长、番茄数、最长连续专注、心流顺延次数、疲劳事件分布与高发时段、离座次数、平均温湿度、每小时活动率；AI 点评 ≤ 300 字 + 2 条建议；语音"今天学得怎么样"播报摘要。
- **验收**：[ ] 统计与原始数据一致（单测）；[ ] 报告页 ≥ 3 张图。

### F-12 线上演示模式
- 演示账号登录 → VirtualEdge 模拟设备、键鼠节奏、电脑工具结果；演示控制台：模拟有人/离开/锁屏、温湿度滑块、打字速率滑块、"对小爱说…"文本框。
- **验收**：[ ] 无硬件条件下三大场景都能在网页走通；[ ] 演示账号无法控制真实硬件。

### F-13 工作台记忆（P1）
- "小爱同学，把现在的工作台记下来，叫数据结构实验" → edge 枚举可见窗口（进程、标题、位置）→ 后端推断项目路径/网址 → 保存为 WorkspaceProfile（自定义布局）。
- **验收**：[ ] 保存后关闭所有窗口，再说"开始数据结构实验"可还原，位置误差 ≤ 40 像素。

### F-14 收工模式（P1）
- "我今天收工了" → 结束会话 → 播报今日摘要 → 台灯 10 秒渐暗关闭 → 空调关闭 → 网页展示日报。

### F-15 分心守护（P1）
- 专注中前台窗口标题/进程命中娱乐名单累计 ≥ 60 秒 → 小爱提醒（每会话 ≤ 3 次，语气递进），记 DistractionEvent。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 快速路径 ≤ 3 s；场景 1 全流程 ≤ 12 s；智能体首次播报 ≤ 6 s（超 2 s 先播"好的，稍等"）；状态推送 ≤ 2 s；edge 常驻 CPU < 3%、内存 < 200 MB |
| 可用性 | 断线指数退避重连（最大 30 s）；edge 离线时网页提示并可切演示模式；任何单个设备/工具失败不导致流程中断 |
| 隐私 | 不用摄像头；键鼠只计数不记录内容；截图不落盘；窗口标题只用于分类，不上传完整标题历史（报告只存分类与进程名） |
| 安全 | edge Token 鉴权；网页 JWT；应用白名单；无任意 shell；危险操作语音二次确认 |
| 可部署 | 云端 `docker compose up -d`；HTTPS；edge 在 Windows 上 `python -m deskmate_edge` 一键启动 |
| 可维护 | 契约文档化；后端核心引擎单测覆盖率 ≥ 70% |
