# DeskMate 答辩技术页素材与讲稿

供成员 C 整合到整套答辩演示稿。这里只提供 B 负责的技术内容和图表，不代做 C 的痛点调研、产品故事、视觉排版、UI 原型或团队博客。建议正文使用下面前两页，共约 70 秒，其余作为答辩备查。所有数值都是设计目标，实测只引用 VALIDATION.md。

## 正文技术页一 系统架构设计

**页面主标题**：系统架构设计

**主体图**：`figures/01_system.svg`。使用矢量图插入，保持比例，不截图压缩。

**可直接放入页面的文字**：

- Windows Edge 主动连接后端，负责设备、电脑工具与感知上报。
- FastAPI 统一维护状态和工具 RPC，协调者决定任务如何执行。
- demo 账号使用独立 VirtualEdge，无硬件也能验证相同接口。
- C 通过规定接口提供健康算法和浏览器页面。

**建议讲稿 30 秒**：

我们的现场端部署在 Windows 上，它负责采集活动统计和执行设备、电脑工具，并主动连接后端。业务决策集中在 FastAPI 平台，浏览器通过 WebSocket 接收状态。为了在没有硬件时也能开发和验收，我们提供独立的 VirtualEdge。演示账号始终走虚拟环境，不会控制真实设备。健康算法由另一模块按约定接口接入。

**讲述边界**：不把现有 API 文档页当作 C 的最终控制台，不把 localhost 成功说成公网已上线。

## 正文技术页二 智能体协同机制

**页面主标题**：智能体协同机制

**主体图**：`figures/02_agents.svg`。图中文字多时仅展示路由、协调者、两个子 Agent、工作台执行器和 EdgeHub 主干，其余用备注解释。

**可直接放入页面的文字**：

- 简单控制先按契约正则匹配，命中后无需调用模型。
- 复杂任务由协调者拆解，再委派环境或电脑 Agent。
- 已知工作台使用确定性流程，环境与电脑并行执行。
- 电脑规划最多六轮，每次调用都经过工具和参数校验。

**建议讲稿 40 秒**：

用户说开灯这类简单命令时，快速路径直接控制设备，避免等待模型。复杂请求由协调者理解和拆解，再交给环境 Agent 或电脑 Agent。比如准备软工作业，执行器会并行调整环境和打开电脑项目，等启动完成再排列窗口。每项动作单独记录结果，一项失败不取消其他项。模型只能使用注册并获准的工具，电脑规划最多六轮，截图也只在内存里送去分析。

**讲述边界**：三秒、十二秒是验收目标，真实语音、模型和硬件延迟需要另测。不要把受控模型测试描述为已接入在线模型。

## 备查页 专注状态与离座响应

**图表**：`figures/03_focus.svg`、`figures/04_presence.svg`。

**核心内容**：锁屏立即暂停；无移动和键鼠空闲都达到三分钟后确认离座；台灯进入百分之十、2500K 伴眠光；确认离座十五分钟关灯和插座，三十分钟关空调；回座恢复剩余计时。心流决策调用 C 接口，由 B 执行顺延，最多两次。

**答辩说明**：只根据活动计数和状态判断，不记录输入字符。看文档时的滚动属于活动，因此不会仅凭低打字数判定离座。无摄像头可以减少隐私侵入，但仍需要真实数据验证疲劳算法，B 不声称已经完成 C 的研究。

## 备查页 数据与验收依据

**图表**：`figures/05_classes.svg`、`figures/06_workspace_sequence.svg`。

**核心内容**：用户配置、工作台、会话与交互日志持久化，状态中心保存最新运行状态。RPC 通过命令 ID 关联 Future，断线清理且不自动重放。验收使用十组语音用例，并区分单元测试、协议模拟、localhost 和真机测量。

## 常见问题与回答要点

| 问题 | B 的回答依据 |
| --- | --- |
| 为什么使用多个 Agent | 将环境和电脑工具权限分开，协调者处理复杂意图，确定性任务仍用代码执行；不是每个控制都调用大模型 |
| 演示会不会误控现场设备 | demo 运行环境、广播、配置和会话按用户隔离，测试覆盖真实 Edge 在线时的隔离 |
| 某个应用打不开会怎样 | 工作台各项独立捕获失败，其他动作继续，汇总失败项而不播报全部成功 |
| 模型响应慢怎么办 | 两秒先确认正在处理，网络与工具都有超时，达到规划上限后给出可解释错误 |
| 截图和键盘是否泄露 | 不采摄像头，不上报按键内容，截图不落盘也不写入会话历史，代码内容从工具日志省略 |
| 空调显示开启就一定开了吗 | 红外无回传，界面保留 inferred=true，只表示最后成功指令，物理执行另验 |
| 健康算法现在实现了吗 | 本轮按分工仅完成 B 的调用与动作接线，评分、心流判断和日报由 C 接入 |
| 已经上线了吗 | 本轮只要求 localhost；实际启动和测试记录见 VALIDATION.md，公网与容器运行不混同 |
