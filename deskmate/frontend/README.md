# DeskMate 桌伴前端

基于 `CONTRACTS.md` v2 实现的 Vue 3 控制台，包含登录、工位首页、工作台管理、智能体对话、演示沙盒、每日复盘和偏好设置。产品流程与设计决策见 [产品设计说明](docs/PRODUCT_DESIGN.md)，实测证据见 [验证记录](docs/VALIDATION.md)。

按新安装的 Taste Skill 完成了 [第二次产品与视觉评审](docs/TASTE_REVIEW.md)，列出了文案、可读性、手机首屏和执行反馈的修改优先级。

第二版的实际修改、检查与上线信息见 [第二版交付记录](docs/V2_DELIVERY.md)。

## 本地运行

使用 Node.js 22.12+ 或 24、pnpm。在本目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173`。选择「打开示例界面」即可在没有后端时体验全部页面；也可直接打开 `http://127.0.0.1:5173/?preview=1`。预览始终标记为本地示例，不连接设备、不调用模型、不持久化修改。

真实联调先按照 `../backend/README.md` 启动后端。Vite 将 `/api`、`/ws` 代理到 `127.0.0.1:8000`；可通过启动环境变量 `DESKMATE_BACKEND` 修改目标。登录 demo 账号使用后端初始化生成的密码，前端不提供默认密码。模型 Key、设备 Token 和 HA 凭据均不进入浏览器配置。

## 操作流程

1. 首页「开始专注」，选择工作台、填写目标与时长；后端准备环境和启动项。
2. 工作台页创建或编辑名称、别名、灯光、空调、启动项、窗口布局。
3. 对话页发送「空调调到25度」，验证快速路径；复杂任务需要管理员配置模型。工具轨迹可展开，完整结果通过右侧抽屉展示。
4. 演示沙盒模拟锁屏、解锁、温度与活动率，实时状态由后端确认。仅 demo 账号可注入事件。
5. 每日复盘查看会话统计、切换日期、导出 Markdown。健康服务未接入时明确展示不可用状态，保留已有的真实会话统计。

## 检查与构建

```bash
pnpm test
pnpm build
pnpm preview
```

构建同时执行 TypeScript 严格检查，产物位于 `dist/`。页面按需加载；Element Plus 按组件导入样式，日期选择器随复盘页加载；图表使用 ECharts core 按需注册。ECharts 图表分块仍约 196 KB gzip，首次进入图表页面时下载，不将构建成功视为网络性能达标。

如需复现本机 REST/WS/SSE 联调，先准备独立演示环境，并在本地创建权限为 0600、被 Git 忽略的 JSON 文件，内容为演示账号的 `username` 与 `password`，再执行：

```bash
node scripts/check-integration.mjs /absolute/path/to/demo-credentials.json http://127.0.0.1:5173
```

脚本仅允许本机 demo 账号，会创建、编辑并删除名为「前端联调专用工作台」的临时工作台，开始/结束测试专注、调节虚拟设备及保存测试设置；应在独立测试数据库上运行。它不输出密码或令牌，不连接真实硬件。

## 前后端边界

- JWT 和账号信息仅存当前标签页的 `sessionStorage`；登出清理状态和对话，过期后返回登录。没有「记住密码」。
- WebSocket 支持 20 秒心跳、60 秒超时与 1/2/4/8/16/30 秒退避。收到快照后丢弃旧增量，按顶层浅合并状态；重连不重放设备操作。
- 设备状态在请求成功后更新；失败保留原值。离线时保留上次快照，并禁用控制操作。
- SSE 使用带 Bearer 的 POST 流读取，支持分块中文、CRLF、多行 data 和服务端错误。停止等待不宣称撤回已执行的动作。
- 模型 Markdown 经 DOMPurify 清理，代码高亮只注册 Python/JavaScript/TypeScript/JSON；禁止远程图片自动加载。
- 当前后端未安装 Wellbeing。疲劳零值不当作健康结论；报告与时序 503 显示服务待接入。个人基线不在当前契约字段中，前端未编造曲线。
- 没有独立「暂停专注」API，前端只提供开始/结束；离座暂停由后端规则触发。
- 网页语音输入仅在浏览器支持 Web Speech 时显示，识别后先填入输入框，由用户确认发送；权限或支持失败可直接输入文字。

## 目录与补充依赖

`src/types/` 契约类型；`lib/` API、SSE、实时连接、Markdown 与预览数据；`stores/` 账号/工位和对话状态；`views/` 六个业务页面与登录；`components/` 图表、图标、Markdown、工位插画与启动项编辑；`tests/` 自动化检查。

在任务卡框架以外，增加 marked、DOMPurify、highlight.js 三个单一用途运行依赖，分别用于 Markdown、安全清理与代码高亮；Prettier 仅用于开发时格式化，jsdom 用于 Vitest 浏览器环境。未新增路由框架，使用固定哈希导航，后端反代不需要额外历史回退路由。字体使用系统字体，无外部字体或图片请求。

## 静态 Demo 构建

`VITE_DEMO_ONLY=true pnpm build` 直接进入独立示例环境；默认构建保留后端登录。Demo 支持设备控制、工作台编辑、规则指令、代码展示与沙盒事件，不调用模型或真实设备。
