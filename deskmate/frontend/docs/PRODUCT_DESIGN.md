# DeskMate 前端产品逻辑与设计说明

日期：2026-11-06。依据：PRD v0.2、ARCHITECTURE v0.2、CONTRACTS v2、任务卡 C；代码基线：远端 `9be66ef`。这是基于既有需求的产品方案，不把需求假设冒充真实问卷结论。

## 1. 用户任务与产品主线

核心用户是长时间在电脑前写作业、写代码和阅读的学生。前端的主线是「准备 → 投入 → 获得帮助 → 复盘」。日常使用时，用户首先关心现在能不能开始、当前环境是否合适、系统有没有执行成功；答辩时，观察者需要能复现事件、看清智能体如何执行。

| 用户时刻 | 首要问题 | 页面和主操作 | 成功反馈 |
| --- | --- | --- | --- |
| 开始前 | 怎么尽快进入状态 | 工位首页：开始专注 | 工作台名称、目标、时钟与设备状态同步 |
| 投入中 | 环境是否舒适，有没有被打扰 | 工位首页：局部设备控制 | 服务端确认的设备状态；连接中断时标明过期 |
| 遇到问题 | 桌伴能否帮我完成 | 桌伴助手：输入一句话 | 流式回复、执行轨迹、完整结果抽屉 |
| 改变场景 | 下次如何快速复用 | 工作台：保存预设 | 名称/别名、启动项、布局、灯光形成一组配置 |
| 回看一天 | 我投入了多少，明天怎么调整 | 每日复盘：选日期、导出 | 可追溯会话统计与服务端报告 |
| 验收演示 | 没有硬件如何看变化 | 演示沙盒：注入事件 | 后端 VirtualEdge 状态变化与规则响应 |

## 2. 信息架构与首页取舍

一级导航为我的工位、工作台、桌伴助手、每日复盘、演示沙盒、偏好设置。首页把专注时钟与关怀状态放在第一视觉层，第二层显示今日投入、在座状态和在线设备，第三层直接控制灯光/空调/插座，最后显示节奏曲线和通知。

开始专注需要选择工作台、目标和时长，不把所有设备参数塞进启动流程。工作台设置负责这些细节。对话提供自然语言替代入口；确定的设备操作仍有直接控制，便于快速调整和验证。首页不放没有接口的「暂停」按钮；暂停与恢复由离座规则处理，结束操作需要确认并保存会话。

## 3. 视觉与组件规范

主色深墨绿 `#315d46`，背景暖白 `#f7f8f4`，卡片白 `#ffffff`，辅助橙用于环境、时间与温暖提示；绿色代表平稳运行，错误与警告同时配文字，避免只凭颜色判断。自绘桌面台灯标志和代码原生 SVG 插画，不依赖远程素材。

使用 8px 级别间距节奏、12px 卡片圆角、低强度边框，减少重阴影和持续闪动。倒计时采用等宽数字；仪表、曲线都同时给出文字说明。图标按钮提供可访问名称，表单字段有标签，键盘焦点可见，中文输入法回车不会误发消息；系统开启减少动态效果时关闭动画。

桌面使用侧栏；800px 以下收为图标栏；600px 以下改为固定底部导航。设备区由三列变为两列，环境卡占满一行，复杂表单改为单列。手机上保留健康状态与退出登录入口。

## 4. 状态与交互原则

| 状态 | 产品反馈 | 实现规则 |
| --- | --- | --- |
| 页面初次加载 | 准备工位提示 | 先读取快照、工作台和设置，再开启实时连接 |
| 登录失败/过期 | 展示原因，返回登录 | 不自动猜测或内置密码；账号切换清除对话与旧请求结果 |
| 设备控制中 | 控件暂时禁用 | 只发送一次，成功后更新，不自动重放 |
| 网络中断 | 显示上次快照并说明 | 自动恢复连接，恢复前禁用操作 |
| 空工作台/空报告 | 明确的下一步 | 可新建工作台；报告没有记录时不画虚假趋势 |
| 健康服务不可用 | 不显示评分结论 | 503 单独处理，真实会话统计仍可查看 |
| 对话正在执行 | 显示回复和工具事件 | 切页面后请求继续；可停止等待并保留收到的内容 |
| 对话未正常结束 | 保留片段，提示执行结果待核对 | 必须收到 done 才算完成，不自动重试设备动作 |
| 空调最后指令态 | 一直标注推测状态 | 不把红外控制当作传感器回读 |
| 界面预览 | 顶部与关键位置标注示例 | 不登录后端，不调用硬件或模型，退出后丢弃示例修改 |

倒计时以服务端阶段结束时间计算，暂停时显示服务端剩余秒数，前端不自主决定阶段切换。真实设备、后端虚拟设备、纯界面预览使用不同标签。健康模块未接入时，后端默认 score=0 不代表精力充沛。

## 5. 实现与接口映射

| 模块 | 实现 | 主要接口 |
| --- | --- | --- |
| 账号与同步 | stores/app.ts、lib/api.ts、lib/realtime.ts | auth/login、state、ws/web |
| 工位首页 | views/Dashboard.vue | devices/*/command、focus/start、focus/stop、timeline |
| 工作台管理 | views/Workspaces.vue | workspaces GET/POST/PUT/DELETE |
| 助手 | views/Chat.vue、stores/chat.ts、lib/sse.ts | chat SSE、assist.result、notify |
| 演示沙盒 | views/Demo.vue | demo/inject |
| 复盘 | views/Reports.vue | focus/sessions、timeline、reports/daily、daily/generate |
| 偏好 | views/Settings.vue | settings GET/PUT |

网页端不直接访问 Home Assistant、小米云或 LLM。所有能力经后端鉴权与工具白名单处理。JWT 只放当前标签页 sessionStorage；新账号不会接收旧异步响应。模型输出先清理再渲染，不允许脚本、表单、远程图片自动加载。

## 6. 当前交付边界与依赖

本轮实现前端页面和后端接口对接，没有把调查、PPT、博客发布、Figma 原型、XMind 或健康算法当作已完成。

健康评分、个人基线、心流决策与 AI 日报后端尚未安装，C-11 和 C-15 服务部分仍待完成。CONTRACTS 只有健康引擎方法签名，DailyReport.stats 的具体字段、基线推送字段及跨日统计口径尚未完整定义。前端现阶段基于已有 FocusSession 字段计算会话统计，不为缺失契约自造服务端字段。工作节奏曲线展示活动率；当前无法把真实个人基线作为第二条线。

部署时需由 B 将 frontend/dist 挂载到 Nginx 静态目录，保持 /api、/ws 同源。公网发布、域名与 TLS、模型/搜索和 Windows 真机联验仍在对应成员交付范围。前端代码中不把 localhost 通过当作已上线。
