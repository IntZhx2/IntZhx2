## 现有后端真实联调

使用仓库原有后端代码和原 requirements.txt，Python 3.12 的独立前端 QA 虚拟环境，不替换成员 B 的运行环境。服务监听 127.0.0.1:8000，Vite 5173 代理 `/api`、`/ws`。测试使用独立 SQLite 与随机生成的临时 demo 凭据，明确 DEMO_MODE=true、LLM Key 为空，不操作 Windows/米家设备，不触碰已有数据库。

`scripts/check-integration.mjs` 实际返回 ok=true，以下九组检查通过：

1. demo 登录与账号类型确认；
2. WebSocket 首次快照；
3. 工作台创建与编辑；
4. 台灯亮度控制及对应 state.patch；
5. 1 分钟专注开始、锁屏暂停、解锁恢复；
6. SSE「空调调到25度」完成，并从 state 确认温度 25；
7. 设置保存和回读；
8. 未安装健康模块时日报明确返回 503；
9. 结束专注并清理联调创建的工作台。

浏览器另行登录真实后端，填写两分钟目标并开始专注；在演示页点击锁屏，等待「已暂停」可见；解锁后「专注中」恢复；对话发送「空调调到24度」，收到服务端「已完成」。复盘页在日报/时序 503 时保留已有会话统计，并禁用重新生成。关闭本轮独立后端后，页面显示正在重连、保留旧快照及控制不可用提示。测试专注已结束，独立后端已停止。

## 五分钟手动复现

依赖安装不计入操作时间。

1. 在 frontend 执行 `pnpm dev`，选择「体验界面预览」。顶部必须显示本地示例标记。
2. 进入工作台，修改名称、启动项后保存；回首页调整灯光和空调，确认预览状态更新。
3. 真实后端启动后，用管理员给出的 demo 密码登录。开始 1 分钟专注，在沙盒锁屏、解锁，检查暂停和恢复。
4. 对话发送「空调调到25度」，检查完成回复及首页温度；复盘页检查已保存会话与当前健康服务不可用提示。
5. `pnpm test && pnpm build`，确认 25 项通过和生产构建成功。
