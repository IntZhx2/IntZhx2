# 性能检查与测量范围

本项目保留 tests/benchmark_profile.py，可在仓库根目录运行：

```bash
python3 smart_agent/tests/benchmark_profile.py
```

它测量 JSON-RPC 对象转换、旧版可逆混淆转换、内存缓存查询和对话压缩。它不请求真实模型或地图服务，不代表整次旅行规划耗时，也不能用来证明密钥存储安全。

本次修复取消原文没有原始采样支持的「缓存快 5000 倍」「上下文平均缩减 65%～75%」等结论。API 响应时间、输出长度、网络和服务商限流都会影响真实延迟。

地图请求使用锁和单调时钟，在当前进程内以最小 0.35 秒间隔分配请求时隙。多进程共享同一 AK 的总配额不由该锁保证；生产环境需集中限流。

自动化测试验证并发时隙、失败恢复和业务边界；通过率不是行覆盖率或分支覆盖率。最新验收结果及局限见 acceptance.md。
